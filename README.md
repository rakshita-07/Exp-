PennyWise — Expense & Trip Management System

PennyWise is a Python-based expense management project designed to help users organize and manage their expenses along with trip-related planning.
The project is structured into multiple Python modules, separating core functionality such as expense management, data handling, trip planning, and the user interface.

✨ Features
Expense management

Trip planning functionality

Persistent data storage using JSON

Modular Python architecture

Separate data-handling and application logic

User interface module for interacting with the application

🛠️ Tech Stack
Python
JSON
Git & GitHub
